# Strategic Field Assessment - YCLI

This repository contains the technical documentation and visual archive for the Youth Community Leadership Initiative (YCLI) conducted in the Sabaragamuwa Province of Sri Lanka between 2021 and 2022. The project focuses on bridging UN strategic frameworks with the rural community needs of the Aranayake Division.

## Project Overview
The initiative represents 12 months of field observations and community engagement designed to identify and address structural community issues. It utilizes the "Healthy Settings" framework to analyze social, environmental, and economic gaps.

## Key Phases
* **Phase 01 / Capacity Building**: Residential training focused on conflict mapping and community needs assessment.
* **Phase 03 / Advanced Training**: Active dialogue and plenary sessions to refine community engagement strategies.
* **Phase 03 / Implementation**: Project mobilization and stakeholder dialogue to drive community impact.

## Technical Features
* **Interactive Narrative**: Smooth scroll animations and element staggering powered by GSAP and ScrollTrigger.
* **Masonry Observation Grid**: A dynamic archive showcasing 17 distinct field data points scanning the local landscape.
* **Responsive Architecture**: Fully optimized for mobile and desktop viewing with high-fidelity typography.
* **Asset Lightbox**: Integrated viewing system for field monitor documentation and asset verification.

## Technology Stack
* **Markup**: HTML5
* **Styling**: CSS3 with custom variables and Flexbox/Grid layouts
* **Animation**: GreenSock Animation Platform (GSAP)
* **Iconography**: Lucide Icons
* **Typography**: Playfair Display and Inter

## Directory Structure
* `YCLI.html`: Main portfolio entry point.
* `Assets/`: Directory containing all field documentation images, hero assets, and the "Community Needs Assessment v.3" PDF document.
